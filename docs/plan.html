Public intake, cloud agent triage

Deliver the specification in dependency order. Task checklist.

Architecture

  1. Run the Apple reader and public issue reconciler on a standard runner in Retain-Feedback. The workflow never writes to private Retain.
  2. Store the Apple review key only in public repository secrets. Keep the public workflow's GitHub token within that repository.
  3. Set up a daily cloud Scheduled task with the connected GitHub app. Its saved instructions, not a local checkout or desktop process, define triage behavior.
  4. The agent checks trusted public review issues, searches private Retain issues across open and closed states, and creates or updates concise backlog work for actionable feedback.
  5. Retire private Retain PR #3 because its private Actions workflow is superseded. Do not merge that workflow.

Order and checkpoints

  1. Build public intake and offline tests. Check: pagination, retry, no-op rerun, edits, spoofed markers, and error handling.
  2. Add the daily/manual public workflow and verify YAML plus source. Check: least-privilege local token, pinned dependencies, no review-text execution, status on failure.
  3. Finish the cloud triage instructions and verify GitHub connector access to both repositories. Check: test a single agent run and repeat without duplicate backlog issues.
  4. Activate the cloud daily schedule in America/Chicago and inspect saved configuration. Check: the task runs independently of this Mac.
  5. Provide Apple App Store Connect API key details through secrets, manually dispatch intake twice, inspect issue results, then observe a scheduled import.

Known external dependencies

  • Apple's Account Holder must enable App Store Connect API access and issue a Customer Support team key before live review collection.
  • A ChatGPT cloud task must be created in an authenticated Scheduled surface; the local Codex automation API exposed to this chat schedules local execution only.
  • The connected GitHub account must retain access to both repositories. A scheduled connected-app write can pause if account policy requires approval.
